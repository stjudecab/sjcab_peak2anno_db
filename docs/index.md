# sjcab_peak2anno_db

Gene-backed peak-to-annotation BED resources for SJ/CAB workflows.

The complete usage guide is maintained in the project repository:

- [README](https://github.com/stjudecab/sjcab_peak2anno_db/blob/main/README.md)
- [Deduplication guide](https://github.com/stjudecab/sjcab_peak2anno_db/blob/main/README.DEDUP.md)
- [Blacklist resources](https://github.com/stjudecab/sjcab_peak2anno_db/tree/main/src/sjcab_peak2anno_db/data/blacklists)

## Installation

```bash
pip install sjcab_peak2anno_db
```

## Quick start

```bash
sjcab-peak2anno-db install
sjcab-peak2anno-db list
```
